## Sobre o Doorpi

O **Doorpi** é um gerenciador de sessões que transforma computadores Windows em uma experiência de console.

Jogos, aplicativos, navegador, streaming e comunicação ficam reunidos em uma única interface feita para usar com controle.

_Doorpi is a session manager that brings games, apps, browsing, streaming and communication together in a controller-friendly console experience for Windows._

---

## Ainda é um beta

O Doorpi ainda está em **beta**. Algumas coisas podem mudar e você provavelmente vai encontrar bugs pelo caminho.

Se testar, me conte o que achou. Bugs, ideias, críticas e sugestões são muito bem-vindos e podem ser enviados pelas [issues do GitHub](https://github.com/Doorpi/Doorpi/issues/new).

_Doorpi is currently in beta. Bugs and changes are expected, and all feedback is welcome through [GitHub Issues](https://github.com/Doorpi/Doorpi/issues/new)._
